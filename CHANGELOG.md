# Changelog

## [0.5.0](https://github.com/PychronLabsLLC/nobion/compare/v0.4.0...v0.5.0) (2026-11-09)


### ⚠ BREAKING CHANGES

* **persistence:** migrating a SQLite store first writes a full copy beside it, <stem>.pre-<from>-to-<to>-<UTC stamp>.sqlite, and a migration whose copy cannot be written is refused (free the disk space and run it again). The copies are never deleted by nobion: remove old ones by hand. elctl db migrate refuses a PostgreSQL store with pending migrations unless --backed-up is given; back it up first with the pg_dump command elctl prints.
* a script's header is #! nobion: (scripts with #! pychron: lose their header values), a release's manifest format is nobion-release/1, the default Postgres user and database are nobion, and EarthBank passwords are kept under the keychain service nobion.earthbank (passwords saved before must be entered again).
* the window's log file is nobion.log and a new install's default SQLite database is data/nobion.db. An existing install keeps working only if its site.toml names its database file; rename data/pychron.db to data/nobion.db and update the site entry otherwise.
* metric names are renamed from pychron_* to nobion_* (nobion_pressure, nobion_executor_state, nobion_scheduler_heartbeat_age_seconds, ...). Dashboards and alert rules from earlier versions find no data; replace them with the ones in packaging/observability.
* CMake options are NOBION_* (NOBION_SANITIZE, NOBION_SCRIPTING, NOBION_VISION_OPENCV, NOBION_PUBLISH, NOBION_PERSISTENCE, NOBION_WARNINGS_AS_ERRORS, NOBION_CCACHE, ...), test binaries are nobion_<component>_tests, and the install components are nobion and nobion_qt. Configure every build directory from scratch.
* run-time folders are renamed: ~/Library/Logs/nobion, ~/Library/Application Support/Nobion (and the XDG and %APPDATA%/%LOCALAPPDATA% equivalents), <install>/.nobion, share/nobion, and default install roots ~/Nobion/<name> and ~/Documents/Nobion. Existing folders under the old names are not read.
* environment variables are renamed from PYCHRON_* to NOBION_* (NOBION_SITE_CONFIG, NOBION_PROFILES_DIR, NOBION_EXAMPLES_DIR, NOBION_TEST_PG_URL, and the NOBION_<FIELD> variables a notification [[command]] receives).
* **observability:** a box set up with the old files must rename its Prometheus job to nobion and replace the provisioning files; docs/observability.md says how. Bookmarks to the old dashboards break.
* **persistence:** run `elctl db migrate --db <url>` on every store. The migration only adds a view: a build before it still opens a migrated store.
* **ui:** the Data window's Publish button opens the Publish dialog; EarthBank publishing now starts from a release.
* **ui:** Enter in the browser adds to Selected instead of recalling; actions no longer fall back to the shown rows.
