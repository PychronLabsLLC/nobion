# grains Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A new app, `grains`, that overlays a `sanidine?`, `not` or `unsure` label and an evidence score on each grain in live microscope video, from the Becke fringe motion of the grain read against a clicked reference grain.

**Architecture:** `libs/grains` (Qt-free, on `core` and `vision`) holds a synchronous `GrainPipeline`, built from small units: segmenter, tracker, fringe measure, pass ledger, score. `GrainRunner` runs it on a worker thread. `apps/grains` is a thin Qt window that draws the reports and offers headless `grains replay`.

**Tech Stack:** C++20, Qt6 Widgets (app only), `libs/vision`, toml++, nlohmann_json, GoogleTest, Qt Test.

**Spec:** `docs/superpowers/specs/2026-10-30-grains-design.md`

## Global Constraints

- `libs/grains` depends on `pychron::core`, `pychron::vision` and `nlohmann_json` only. No Qt and no OpenCV headers.
- `GrainPipeline` has no clock of its own: `Frame::timestamp` is its only time, and its output is deterministic for given frames.
- `GrainPipeline` uses no z value and assumes no direction of the rack. Comparison with the reference at the same moment is the only use of z.
- On-screen label text is exactly `sanidine?`, `not`, `unsure`. Never bare `sanidine`.
- No `Candidate` or `Not` label exists while no reference has been set.
- UI text says "score", never "probability" or "confidence %".
- Defaults: `min_passes` 3, `min_score` 0.8, `min_fps` 10.
- `score = (agree + 1) / (agree + against + 2)`.
- Errors are `Result<T>`. Warnings as errors. gcc, clang 18 and MSVC rules of root `AGENTS.md` apply.
- App tests live beside the app, `apps/grains/tests`, as `apps/elctl` does.
- `apps/grains` is built under `BUILD_UI` and only when target `pychron_grains` exists. Its tests need preset `dev-ui`.
- Domain seam untouched: no Ar-Ar, no `Domain` entry.

## Review Focus

- A reference grain drifting to the frame edge or out of view: state goes to `Lost`, no new votes, labels held, no crash. Test in Task 7.
- Grains touching or clumping so two blobs merge, then split: a merged blob is a new track with no votes, never one that inherits. Test in Task 4.
- A grain cut off by the frame edge: its outline cannot be trusted, so it stays `Unsure` however its fringe moves. Test in Task 7.
- Focus racked so fast or stopped so long that no pass forms: no votes, labels unchanged, state `MoveFocus`. Test in Task 7.
- Camera reopening at a different frame size mid-session, or a blank frame: reset, no crash, no stale outline. Test in Task 7.

struct SynthGrain {
  vision::Vec2 center;
  double radius_px = 40;
  double elongation = 1.0;  // x radius = elongation * radius_px
  double delta_n = 0;       // grain index minus oil index
};
struct GrainScene {
  int width = 640, height = 480;
  std::uint16_t pixel_depth = 255;
  std::vector<SynthGrain> grains;
  double oil_level = 0.6;      // fraction of pixel_depth
  double edge_level = 0.04;    // step of the grain body: its outline at any delta_n
  double fringe_gain = 10.0;   // fringe height = |delta_n| * fringe_gain, fraction of depth
  double fringe_px_per_z = 8.0;
  double fringe_sigma_px = 2.0;
  double noise = 0.002;        // gaussian sigma, fraction of depth
  std::uint32_t seed = 1;
};
using ZScript = std::function<double(double t_s)>;
using ShiftScript = std::function<vision::Vec2(double t_s)>;
ZScript triangle_z(double period_s, double amplitude);
vision::Frame render_scene(const GrainScene&, double z, vision::Vec2 shift);
class GrainSynth final : public vision::IFrameSource {
 public:
  GrainSynth(GrainScene, ZScript, double fps, ShiftScript shift = {});

  vision::FrameInfo info() const override;
};

- Produces:

```cpp
class PassLedger {
 public:
  explicit PassLedger(const GrainOptions&);
  struct Sample { std::uint64_t id; double velocity_px_s; double contrast; };
  void update(TimePoint t, double reference_velocity, double reference_contrast,
              std::span<const Sample> grains);
  void drop_pass();                       // throw away the pass in progress
  void forget(std::uint64_t id);
  Tally tally(std::uint64_t id) const;    // zeros for an unknown id
  Vote last_vote(std::uint64_t id) const;
  bool pass_running() const;
  void reset();
};
```

A pass is a run of frames with `reference_velocity` of one sign at or above `min_ref_speed_px_s`. It closes when the sign changes or speed falls below; it counts only with at least `min_pass_frames` frames. At close, for each grain seen in the pass: displacement is the integral of velocity, reference displacement likewise, mean contrast over the pass. `None` when mean contrast is below `min_contrast`, else `Same` or `Opposite` by sign of the product. Weight is `min(1, grain contrast / reference contrast)`.
